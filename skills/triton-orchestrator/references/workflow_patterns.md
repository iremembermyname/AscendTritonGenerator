# 工作流模式

本文档定义了Triton算子生成系统的标准工作流模式。

---

## 1. 算子生成工作流

```
用户输入: "帮我生成一个融合softmax算子"
    │
    ▼
┌─────────────────────────────────────┐
│  1. 任务分析                         │
│  - 提取算子名称: softmax             │
│  - 提取规格: 融合类型                │
│  - 确定数据类型: 默认BF16            │
└─────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────┐
│  2. 创建Session                      │
│  - 生成session_id                    │
│  - 创建目录结构                       │
│  - 写入task.json                     │
└─────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────┐
│  3. 调用代码生成Skill                │
│  - 输入: design/input.json           │
│  - 输出: code/output.py              │
└─────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────┐
│  4. 检查NPU环境                      │
│  - 有NPU: 继续验证                   │
│  - 无NPU: 跳过验证，输出代码          │
└─────────────────────────────────────┘
    │
    ├─── 无NPU ──→ 输出代码，结束
    │
    ▼ 有NPU
┌─────────────────────────────────────┐
│  5. 调用精度验证Skill                │
│  - 输入: verification/input.json     │
│  - 输出: verification/result.json    │
└─────────────────────────────────────┘
    │
    ├─── 验证失败 ──→ 错误处理流程
    │
    ▼ 验证通过
┌─────────────────────────────────────┐
│  6. 询问是否需要性能优化             │
│  - 需要: 调用性能优化Skill           │
│  - 不需要: 生成报告                   │
└─────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────┐
│  7. 生成最终报告                     │
│  - 汇总各阶段结果                    │
│  - 输出代码文件路径                  │
│  - 输出验证结果                      │
│  - 输出性能数据（如有）              │
└─────────────────────────────────────┘
```

## 2. 代码优化工作流

```
用户输入: "优化这段softmax代码的性能"
    │
    ▼
┌─────────────────────────────────────┐
│  1. 任务分析                         │
│  - 提取目标代码                      │
│  - 提取优化目标                      │
│  - 分析当前性能                      │
└─────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────┐
│  2. 性能分析                         │
│  - 运行性能测试                      │
│  - 识别瓶颈                          │
│  - 生成分析报告                      │
└─────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────┐
│  3. 调用性能优化Skill                │
│  - 输入: optimization/input.json     │
│  - 输出: optimization/optimized.py   │
└─────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────┐
│  4. 验证优化后代码                   │
│  - 精度验证                          │
│  - 性能对比                          │
└─────────────────────────────────────┘
    │
    ├─── 未达标 ──→ 迭代优化（最多3次）
    │
    ▼ 达标
┌─────────────────────────────────────┐
│  5. 生成优化报告                     │
│  - 优化前后对比                      │
│  - 应用的优化技术                    │
│  - 性能提升数据                      │
└─────────────────────────────────────┘
```

## 3. 代码转换工作流

```
用户输入: "把这个CUDA kernel转换成Ascend版本"
    │
    ▼
┌─────────────────────────────────────┐
│  1. 任务分析                         │
│  - 提取源代码                        │
│  - 识别CUDA特性                      │
│  - 确定转换范围                      │
└─────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────┐
│  2. 调用CUDA转换Skill                │
│  - 分析CUDA代码                      │
│  - 识别差异点                        │
│  - 生成Ascend代码                    │
└─────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────┐
│  3. 兼容性检查                       │
│  - 检查API兼容性                     │
│  - 检查硬件限制                      │
│  - 生成兼容性报告                    │
└─────────────────────────────────────┘
    │
    ├─── 有兼容性问题 ──→ 询问用户
    │
    ▼ 无问题
┌─────────────────────────────────────┐
│  4. 精度验证                         │
│  - 对比转换前后结果                  │
│  - 验证数值一致性                    │
└─────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────┐
│  5. 生成转换报告                     │
│  - 转换前后代码对比                  │
│  - 差异说明                          │
│  - 验证结果                          │
└─────────────────────────────────────┘
```

## 4. 知识添加工作流

```
用户输入: "发现了一个问题，记录到知识库"
    │
    ▼
┌─────────────────────────────────────┐
│  1. 知识分析                         │
│  - 提取知识内容                      │
│  - 确定知识类型                      │
│  - 提取关键信息                      │
└─────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────┐
│  2. 调用知识管理Skill                │
│  - 验证知识质量                      │
│  - 检查重复/冲突                     │
│  - 选择存储位置                      │
└─────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────┐
│  3. 知识存储                         │
│  - 写入知识库文件                    │
│  - 更新索引                          │
│  - 生成更新日志                      │
└─────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────┐
│  4. 生成确认报告                     │
│  - 知识摘要                          │
│  - 存储位置                          │

└─────────────────────────────────────┘
```

## 5. 问题诊断工作流

```
用户输入: "为什么这个kernel报错了"
    │
    ▼
┌─────────────────────────────────────┐
│  1. 错误分析                         │
│  - 提取错误信息                      │
│  - 分析错误类型                      │
│  - 定位问题位置                      │
└─────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────┐
│  2. 知识检索                         │
│  - 检索相似案例                      │
│  - 检索相关规则                      │
│  - 获取解决方案                      │
└─────────────────────────────────────┘
    │
    ├─── 找到解决方案 ──→ 应用修复
    │
    ▼ 未找到
┌─────────────────────────────────────┐
│  3. 深度分析                         │
│  - 分析代码逻辑                      │
│  - 检查硬件约束                      │
│  - 生成诊断报告                      │
└─────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────┐
│  4. 提供解决方案                     │
│  - 说明问题原因                      │
│  - 提供修复建议                      │
│  - 询问是否应用                      │
└─────────────────────────────────────┘
```

## 6. 错误处理工作流

```
错误发生
    │
    ▼
┌─────────────────────────────────────┐
│  1. 错误分类                         │
│  - 编译错误 / 精度错误 / 性能问题    │
│  - 简单 / 复杂                       │
└─────────────────────────────────────┘
    │
    ├─── 简单错误 ──→ 自动修复 ──→ 验证
    │                               │
    │                               ├─── 成功 ──→ 继续
    │                               │
    │                               └─── 失败 ──→ 重试(最多5次)
    │
    └─── 复杂错误 ──→ 询问用户
```

## 7. Session状态管理

### 7.1 状态定义

| 状态 | 说明 |
|------|------|
| created | Session已创建 |
| analyzing | 正在分析任务 |
| generating | 正在生成代码 |
| verifying | 正在验证精度 |
| optimizing | 正在优化性能 |
| completed | 任务完成 |
| failed | 任务失败 |
| paused | 等待用户输入 |

### 7.2 状态转换

```
created → analyzing → generating → verifying → optimizing → completed
    │          │           │            │            │
    │          │           │            │            └──→ failed
    │          │           │            └──→ failed
    │          │           └──→ failed
    │          └──→ paused (等待用户输入)
    └──→ failed
```
