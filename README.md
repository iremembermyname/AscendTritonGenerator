# Ascend Triton 算子生成智能体

一个基于 Skill 架构的 Ascend Triton 算子自动生成系统，支持代码生成、精度验证、性能优化和知识管理。

## 项目概述

### 背景

大模型主要具备 CUDA Triton 的能力，而 Ascend Triton 文档不完善。本系统旨在：

- 自动生成 Ascend Triton 算子
- 在实际应用中发现问题后方便地添加新知识
- 支持 NPU 验证精度和性能，迭代调试和优化

### 设计目标

- **轻量级**：可在 Claude/Trae 等 IDE 中以 skill 形式使用
- **主从模式**：主编排器 skill 协调各功能 skill 完成复杂任务
- **知识驱动**：支持知识自动吸收和更新
- **智能决策**：简单问题自动处理，复杂问题询问用户

## Skill 说明

| Skill | 核心职责 | 输入 | 输出 |
|-------|---------|------|------|
| triton-orchestrator | 任务分析、流程编排、错误处理、结果整合 | 用户需求描述 | 执行计划、最终报告 |
| triton-code-generator | 根据设计生成 Triton 代码、修复代码错误 | 设计文档/错误信息 | Triton 代码 |
| triton-precision-verifier | 精度验证、测试数据生成、问题分析 | Triton 代码+参考实现 | 验证结果+报告 |
| triton-performance-optimizer | 性能分析、优化建议、优化代码生成 | Triton 代码+性能目标 | 优化后代码+报告 |
| cuda-to-ascend-converter | CUDA 代码分析、语法转换、兼容性检查 | CUDA Triton 代码 | Ascend Triton 代码 |
| ascend-knowledge-manager | 知识吸收、分类索引、检索服务 | 新知识/查询请求 | 更新日志/检索结果 |

## 知识库分层

### 静态知识 vs 动态知识

| 类型 | 存储位置 | 更新方式 | 内容示例 |
|------|---------|---------|---------|
| **静态知识** | skill 的 references/ | 随 skill 版本更新，手动维护 | Triton 语法、Ascend API 文档、代码模板 |
| **动态知识** | 全局 knowledge/ | 运行时自动更新 | 案例、规则、经验文档 |

### 知识检索策略

各 skill 执行时按以下顺序检索知识：

1. skill 自己的 `references/` → 基础知识，总是加载
2. 全局 `knowledge/` → 动态知识，按需检索

## 智能决策模式

### 错误分类与处理

| 错误类型 | 特征 | 处理方式 |
|---------|------|---------|
| 简单编译错误 | 编译失败 + 错误信息明确 + 修复方案清晰 | 自动修复 |
| 复杂编译错误 | 编译失败 + 错误信息模糊/不明确 | 询问用户 |
| 简单精度错误 | 数值偏差小 + 原因明确 + 修复方案清晰 | 自动修复 |
| 复杂精度错误 | 数值偏差大/原因不明确 | 询问用户 |
| 性能问题 | 精度正确但性能不达标 | 先尝试优化→搞不定再询问用户 |
| 硬件限制错误 | 超出硬件资源限制 | 询问用户 |

### 重试策略

- 最大重试次数：5 次
- 同类错误连续出现：3 次后询问用户
- 性能优化尝试次数：3 次
- 总执行时间限制：30 分钟

## 预期效果

1. **快速生成**：用户输入需求，系统自动完成设计→生成→验证→优化全流程
2. **知识积累**：每次成功/失败案例都能沉淀为知识，持续改进
3. **智能决策**：减少不必要的用户交互，复杂问题才询问
4. **易于扩展**：新增 skill 只需遵循规范，主编排器自动集成
5. **知识分层**：静态知识稳定可靠，动态知识自动积累
